# Space Dodge Game 🚀

A simple yet addictive space-themed dodge game built with Pygame where you control a spaceship and avoid falling stars for as long as possible!

## 📋 Description

Space Dodge is a survival game where players navigate a spaceship at the bottom of the screen, dodging an increasingly difficult barrage of red stars falling from above. The game progressively becomes more challenging as stars spawn more frequently the longer you survive.

## ✨ Features

- **Dynamic Difficulty**: Stars spawn faster as time progresses
- **Score Tracking**: Live timer showing how long you've survived
- **Smooth Controls**: Responsive left and right movement
- **Custom Graphics**: Space-themed background with a cyan triangle spaceship
- **Game Over Screen**: Displays "You Lost!" message when hit

## 🎮 How to Play

- **Left Arrow Key**: Move spaceship left
- **Right Arrow Key**: Move spaceship right
- **Objective**: Avoid the falling red stars for as long as possible!

## 🛠️ Requirements

- Python 3.x
- Pygame library

## 📦 Installation

1. Clone this repository:
   ```
   git clone https://github.com/uzair99x/space_dodge_game.git
   cd space-dodge-game
   ```

2. Install the required dependencies:
   ```
   pip install pygame
   ```

3. Make sure you have a background image file named `BackG.jpg` in the same directory as the game file.



## 🎨 Customization

You can easily customize the game by modifying these variables in the code:

- `PLAYER_VEL`: Player movement speed (default: 5)
- `STAR_VEL`: Star falling speed (default: 3)
- `PLAYER_WIDTH` & `PLAYER_HEIGHT`: Spaceship dimensions
- `STAR_WIDTH` & `STAR_HEIGHT`: Star dimensions
- Colors: Change 'cyan' for spaceship and 'red' for stars
